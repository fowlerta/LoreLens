# LoreLens Roadmap

> A browser extension for immersive reading with offline dictionary support, designed for fantasy literature and language learners.

## Vision

LoreLens aims to provide instant contextual information for any selected word on a webpage without leaving the current page.

The extension will prioritize lore dictionaries (e.g. Tolkien Gateway) while also supporting traditional English dictionaries, pronunciation, notes, and vocabulary learning.

Everything should work locally whenever possible.

---
